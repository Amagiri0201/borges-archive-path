### 02 图书馆人生（library-life）
- 副标题: 编目、失明与无限书架
- 时间: 1938-1955
- 生平: 博尔赫斯曾在 Miguel Cane 图书馆工作，1955 年出任阿根廷国家图书馆馆长；失明与图书馆经验交织成强烈的生命隐喻。
- 文本: 《巴别图书馆》 / 《赠予之诗》
- 母题: 图书馆 / 失明 / 无限

- 用户动作提示: 点击工作台、黑暗书架和六边形结构，进入图书馆母题。

> 每个热点打开后出现思想回声面板。基础结构为：声音标签、母题标签、标题、主回应、证据、收藏按钮、追问按钮。

### 00 进入档案 / 档案入口
- 键值: archive-entry:archive-door

- 标题: 档案入口
- 母题: 档案 / 入口 / 路径
- 主回应: 不要把这当成目录。目录只是伪装；真正展开的是一个人的生平如何变成文本结构。
- 证据: 项目结构 / Borges biography
- 收藏按钮: 记录入口
- 收藏提示: 把入口加入你的阅读路径。
- 追问
  - 追问这个意象（motif）: 入口的意义不是“开始”，而是允许你承认自己还没有地图。博尔赫斯式的阅读总是先迷路，再理解迷路的结构。
  - 它和文本怎么连？（evidence）: 这个入口会把生平、作品、地点和母题绑定在一起。我们不是在介绍人物，而是在搭一座可追溯的文学档案。

### 00 进入档案 / 父亲藏书

- 主回应: 这座迷宫不是从公共图书馆开始的。它先从父亲的书房开始：英语书、翻译和异国故事，把童年的房间变成第一座图书馆。

  - 它和文本怎么连？（evidence）: 传记资料常把博尔赫斯的早年阅读和家庭藏书联系在一起。这里把它转译成全站的第一个空间母题。

### 01 城市记忆 / 早期诗歌

  - 它和文本怎么连？（evidence）: 《布宜诺斯艾利斯激情》是博尔赫斯早期诗集，适合作为城市记忆章节的文本锚点。

### 01 城市记忆 / 南方边缘

### 02 图书馆人生 / 编目工作台
- 键值: library-life:miguel-cane
- 声音标签: 档案员
- 标题: 编目者
- 母题: 图书馆 / 编目 / 隐秘写作
- 主回应: 白天，他给书分类。空隙里，他写下另一种分类法：把世界分成镜子、梦、图书馆和不可能的书。

  - 它和文本怎么连？（evidence）: Buenos Aires 相关资料提到 Miguel Cane 图书馆与博尔赫斯的工作经历，这里转译为“工作台”热点。

### 02 图书馆人生 / 书与黑夜
- 键值: library-life:books-night
- 声音标签: 索引感
- 标题: 书与黑夜
- 母题: 失明 / 图书馆 / 命运悖论
- 主回应: 命运把书和黑夜同时交给他。这不是悲剧说明，而是博尔赫斯式悖论：越接近全部书籍，越无法用眼睛阅读。
- 证据: National Library / blindness motif
- 收藏按钮: 收入黑夜书架
- 追问
  - 追问这个意象（motif）: 黑夜不是知识的反面。它逼迫阅读从视觉转向记忆、声音和想象，反而让图书馆变得更巨大。
  - 它和文本怎么连？（evidence）: 1955 年出任国家图书馆馆长与失明经验常被并置讨论，这一节点承担生平和母题的连接。

### 02 图书馆人生 / 六边形书库
- 键值: library-life:hexagon
- 声音标签: 索引感
- 标题: 六边形书库
- 母题: 无限 / 组合 / 秩序与混乱
- 主回应: 无限不是浪漫的远方。在图书馆里，无限更像一种冷酷排列：所有可能都存在，因此意义更难被找到。
- 证据: The Library of Babel / Ficciones
- 收藏按钮: 追踪无限文本
- 追问
  - 追问这个意象（motif）: 六边形让无限变得可视。它越规则，就越可怕：秩序并没有拯救人，秩序只是更精确地展示了迷失。
  - 它和文本怎么连？（evidence）: 《巴别图书馆》的空间想象是本项目视觉底图的重要母题，适合做书架和几何热点。

### 03 小径分岔 / 交汇节点

  - 它和文本怎么连？（evidence）: 这一节点对应《小径分岔的花园》的核心结构：时间不是单线，而是分岔的并存可能。

### 03 小径分岔 / 选择时间

### 03 小径分岔 / 选择镜像

### 03 小径分岔 / 选择城市

  - 它和文本怎么连？（evidence）: 城市路径把《小径分岔》重新接回生平地理，让抽象迷宫落回现实空间。

### 03 小径分岔 / 并存路径

  - 它和文本怎么连？（evidence）: 镜像母题贯穿博尔赫斯作品，这里作为“自我不稳定”的入口。

### 04 镜像与梦 / 另一个我
- 键值: mirror-dream:double-self

- 标题: 另一个我
- 母题: 分身 / 误认 / 作者身份

  - 它和文本怎么连？（evidence）: 这一热点把镜像章节和环形废墟章节连接起来：分身问题最终会变成创造者问题。

### 04 镜像与梦 / 梦的入口
- 键值: mirror-dream:dream-gate

### 05 环形废墟 / 仪式圆环

### 05 环形废墟 / 被梦见的人

### 05 环形废墟 / 火焰启示

  - 它和文本怎么连？（evidence）: 这个结尾让“虚构生成现实”形成闭环，适合做章节中的第三个强热点。

### 06 阿莱夫 / 中心光点
- 键值: aleph:aleph-core
- 声音标签: 光点
- 标题: 阿莱夫
- 母题: 总体性 / 无限视觉 / 语言失败
- 主回应: 这里不是一盏灯。它是一个不可能的观看位置：所有地点、所有时间、所有记忆同时挤进一个点。

  - 它和文本怎么连？（evidence）: 《阿莱夫》围绕一个能看见总体的点展开，本章把它作为全站母题网络的中心。

### 06 阿莱夫 / 节点爆发
- 键值: aleph:node-burst

- 标题: 不可说的观看
- 母题: 经验过载 / 语言顺序 / 万物同时

  - 它和文本怎么连？（evidence）: 这个热点解释为什么视觉爆发不能只是炫技：它对应的是“经验超过叙述能力”的文学问题。

- 键值: aleph:language-collapse

- 标题: 语言失序
- 母题: 叙述失败 / 同时性 / 总体索引

- 追问
  - 追问这个意象（motif）: 句子只能一字一字写，阿莱夫却一瞬间给出全部。这里的裂缝，就是文学和视觉之间的裂缝。
  - 它和文本怎么连？（evidence）: 这个新增热点用于解释本页的粒子、节点和文字漂浮：它们不是装饰，而是语言失序的界面表现。

### 07 沙之书 / 无限页码
- 键值: book-of-sand:sand-pages
- 声音标签: 沙粒
- 标题: 没有第一页
- 母题: 无限文本 / 页码 / 阅读困境
- 主回应: 一本没有第一页的书，也不会有最后一页。读者不再掌握文本，文本反过来困住读者。
- 证据: The Book of Sand / 1975
- 收藏按钮: 收入无限页码
- 追问
  - 追问这个意象（motif）: 页码本来是秩序工具。可如果页码无法抵达开头和结尾，秩序本身就变成了恐惧。
  - 它和文本怎么连？（evidence）: 《沙之书》把无限从空间转移到书页，本页的漂浮书封就是这个转译。

### 07 沙之书 / 句子碎片
- 键值: book-of-sand:floating-quotes
- 声音标签: 沙粒
- 标题: 文本碎片
- 母题: 碎片 / 收集 / 个人阅读路径
- 主回应: 你无法拥有整本书。你只能带走几个碎片，并假装它们足以证明你曾经进入过无限。
- 证据: The Book of Sand / late Borges
- 收藏按钮: 收入文本碎片
- 追问
  - 追问这个意象（motif）: 碎片比全集诚实。它承认你永远无法带走全部，但仍允许你留下经过的痕迹。
  - 它和文本怎么连？（evidence）: 收集系统会把这些碎片汇总到最后的档案室，形成用户自己的阅读路径。

### 07 沙之书 / 隐藏书架
- 键值: book-of-sand:hidden-shelf
- 声音标签: 沙粒
- 标题: 藏回书架
- 母题: 恐惧 / 秩序 / 无法占有
- 主回应: 当无限无法被读完，唯一的策略也许是把它藏起来，让恐惧暂时伪装成秩序。
- 证据: The Book of Sand / ending motif
- 收藏按钮: 收入隐藏书架
- 追问
  - 追问这个意象（motif）: 把书藏起来不是解决无限，而是把无限从视线中移走。人类经常把不可处理的东西称为“已经收纳”。
  - 它和文本怎么连？（evidence）: 这个热点对应《沙之书》的阅读困境：无限文本并不会因为被放回书架而消失。

## 6. 演示时可用的交互逻辑讲法

1. 观众通过顶部章节轨道或“下一章”在同一张空间地图中移动。
2. 每章左侧给出时间、生平、文本和母题，右侧底图承担该章节的视觉叙事。
3. 点击热点后进入“思想回声”面板，面板提供主解释、文本证据和可追问回应。
4. 在“小径分岔”章节，路径选择会改变全站的阅读路径状态。
5. 在“沙之书”章节，用户已收藏的碎片汇总为个人阅读路径。
6. 在“档案室”章节，项目回到来源墙和方法说明，回应数字人文作业对准确性的要求。
